Conversor de Tabelas para XLSX
Conversor web de XLS, XLSX, XML, CSV, TXT e TSV para `.xlsx`.

Privacidade
O processamento é feito no navegador. Os arquivos escolhidos pelo usuário não são enviados por este aplicativo a um servidor para conversão.

Observação sobre XML
XML pode representar estruturas hierárquicas, não apenas tabelas. O aplicativo tenta detectar grupos de registros repetidos e achatá-los para linhas e colunas. Confira a saída de XMLs complexos.
